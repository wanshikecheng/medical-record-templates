# 病历书写规范与时限

> 汇总病历书写中容易出错的规范要求，可作为自查清单使用。**具体时限与格式以国家卫生健康行政部门规定和本院病案管理要求为准。**

---

## 一、时限要求（常见）

| 文书 | 时限 |
|---|---|
| 入院记录 | 患者入院后 **24 小时内**完成 |
| 首次病程记录 | 患者入院后 **8 小时内**完成 |
| 上级医师首次审核 | 主治医师应在 **48 小时内**对入院记录、首次病程记录审核修改并签名 |
| 日常病程记录 | 按病情需要，危重患者随时记录 |
| 术前小结 | 手术前完成（时间早于手术开始） |
| 术后首次病程记录 | 手术当日、术毕安返病房后及时书写（一般 6 小时内） |
| 出院记录 | 患者出院时（前有出院当天查房记录） |

---

## 二、书写铁律（自查清单）

### 1. 时间线自洽
- 入院 → 查房 → 术前小结 → 手术 → 术后病程 → 出院，顺序不能乱
- 术前小结时间 < 入手术室时间 < 手术结束时间 < 术后首次病程记录时间
- 术后逐天病程的日期必须与手术日期连贯（术后第 1 天 = 手术次日）
- 查房记录中的新结果，必须有对应的医嘱或报告出处

### 2. 数据不臆造
- **严禁编造**：出血量、手术持续时间、病理结果、化验数值、生命体征实测值
- 未提供的关键数据：先确认；确实无法获取时用"XXX"或"待完善"占位并标注需补全
- 化验单/医嘱/资料中没有的检查结果，不得写入

### 3. 内容对应
- 专科查体的阳性体征要与影像/化验结果**对应**（如影像示突出节段与查体神经定位一致）
- 触诊尺寸与影像测量可有合理差异，但"有无包块/有无压痛"等定性结论不得矛盾
- 诊断分级、分期、分型要与病情描述一致

### 4. 表述规范
- 使用规范医学术语，口语转书面语（"肚子疼"→"腹痛"）
- 诊断使用**病案首页规范名称**，不使用俗称
- 日常病程与查房记录按科室习惯书写（常见为整段式连贯叙述，不逐条分项）
- 切口分类与愈合分级表述规范且与实际一致

### 5. 缺失项处理
- 未查项目写「未查」
- 尚无结果写「待完善」
- 不确定的数值标注「(待确认)」
- 不用"待补充""见上"这类含糊或半成品表述

### 6. 隐私与代称
- 对外分享、教学使用的病历示例，患者与医师姓名一律用"XXX"替代
- 身份证号、手机号、住址等个人标识信息应脱敏处理
- 新生儿不写姓名，只写"男婴/女婴"

## 三、常见错误（高频自查项）

| 错误类型 | 表现 | 修正 |
|---|---|---|
| 时限错乱 | 首程写了入院次日才出的化验结果 | 首程只用入院当天及之前的结果 |
| 手术无出处 | 病程中突然出现手术，前序文书无手术决策记录 | 三级查房记录写主任拟定术式与日期 → 术前小结 → 术前医嘱 |
| 数据编造 | 出血量、手术时间凭印象写 | 以手术记录/麻醉记录为准，缺失则确认 |
| 诊断不一致 | 入院诊断与出院诊断无解释地不同 | 有修正需在诊疗经过中说明原因 |
| 出院医嘱含糊 | 写"详见出院小结""遵医嘱用药" | 序号列出药名/剂量/用法、复诊时间与科室、换药拆线安排 |
| 术语不统一 | 同一体征多种表述 | 统一术语表述 |
| 辨征不符 | 查体所述部位与主诉/影像不一致 | 核对主诉、查体、影像三者一致性 |
| 内容矛盾 | 前文"无过敏史"，后文写了过敏药物 | 通篇交叉核对 |

---

## 四、跨文书一致性检查（推荐流程）

写完一套病历时，按以下顺序对照检查一遍：

1. **患者基本信息**：各文书中的年龄、性别、住院号一致
2. **主诉 ↔ 现病史**：主诉症状必须在现病史中有展开
3. **现病史 ↔ 查体**：症状部位与查体阳性体征对应
4. **查体 ↔ 辅助检查**：影像/化验结果支持查体描述，不出现矛盾
5. **诊断链条**：初步诊断 → 查房中的诊断修正 → 出院诊断，逐次演进有依据
6. **手术链条**：查房决策 → 术前小结 → 术前医嘱 → 手术记录 → 术后病程，术式与日期一致
7. **医嘱 ↔ 病程**：病程中提到的治疗与医嘱记录对应（用药、禁食、引流、复查）
8. **出院医嘱完整性**：用药、复诊、换药拆线、病理复诊、注意事项无缺项
