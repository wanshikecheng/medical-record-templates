# 病历模块定义

> 用于把病历拆成可核对、可生成、可复查的结构化模块。住院病历采用 **11 个标准模块**；门诊病历采用 **客观记录四栏**（不设诊断/处理栏）。

---

## 一、住院病历：11 个标准模块

| # | 模块 | 字段（书写要点） |
|---|---|---|
| 1 | **现病史** | 起病情况、症状特点、诊治经过、一般情况 |
| 2 | **既往史** | 既往疾病、手术外伤史、过敏史、个人史 |
| 3 | **辅助检查** | 实验室检查、影像学检查、特殊检查 |
| 4 | **专科情况** | 专科查体要点（阳性体征 + 程度分级 + 关键阴性体征） |
| 5 | **鉴别诊断** | 需鉴别的疾病、鉴别要点 |
| 6 | **诊疗计划** | 治疗措施、护理要点、随访安排 |
| 7 | **一级查房记录** | 病情变化、查体要点、上级医师意见 |
| 8 | **二级查房记录** | 病情分析、治疗方案调整 |
| 9 | **三级查房记录** | 主任医师意见、诊疗方向 |
| 10 | **手术记录** | 术前诊断、术中情况、手术经过、术后处理 |
| 11 | **出院记录** | 入院情况、入院诊断、诊疗经过、出院诊断、出院情况、出院医嘱 |

**说明**：
- 模块化书写的好处：可逐项核对完整性、可单独补充某一块、便于多份文书之间保持一致性
- 各科室可在 11 模块之外**自建模块**（如中医辨证、康复评定、特殊量表）
- 模块之间的**时间与内容必须一致**：例如「手术记录」里的术式必须与「三级查房记录」中的手术决策、"术前小结"的拟施术式一致

## 二、门诊病历：客观记录四栏

门诊场景以**口述记录**为主，只记录客观内容：

| 栏位 | 内容要点 |
|---|---|
| **主诉** | 主要症状 + 持续时间，一句话 |
| **现病史** | 起病情况、病情演变、诊疗经过、一般情况（食欲/睡眠/二便/体重） |
| **体格检查** | 生命体征（T/P/R/BP）+ 专科查体（按症状部位检查所见）；未查到的写"未查" |
| **辅助检查** | 本次相关检查结果（化验/影像等），无则写"暂无" |

### 门诊病历红线（重要）

门诊记录**只做客观记录**：

- **不设**「初步诊断」「处理意见」「用药」栏位
- **不生成**诊断结论、治疗方案、用药名称与剂量
- 医师口述中提到的诊断、方案、药物，**原样保留在口述转写区**，不整理进栏位、不推断、不补充
- 客观缺失项写「未查」或「待完善」，**严禁臆造**

> 原因：门诊记录的定位是"如实记录医师口述的客观内容"，诊断与处置由医师本人判断并另行书写，辅助工具不应替代判断。

---

## 三、模块化书写的实践建议

1. **先立结构，再填内容**：先确定本次要写哪些文书，再逐模块填写
2. **一模块一核对**：每个模块写完后对照字段清单检查是否有缺项
3. **跨文书一致性检查**：入院记录 ↔ 首程 ↔ 查房 ↔ 术前小结 ↔ 手术记录 ↔ 出院记录的诊断、术式、日期必须前后一致
4. **缺失项显式标注**：宁可标"未查/待完善"，不要留空、不要编造
5. **术语统一**：同一体征、同一诊断在同一份病历中用同一表述
