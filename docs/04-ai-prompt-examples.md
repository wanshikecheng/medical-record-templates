# AI 辅助书写的提示词示例

> 以下提示词可直接用于让大语言模型辅助整理/生成病历草稿。**生成结果必须由执业医师审核修改后使用。**

---

## 一、核心原则（先约束 AI，再让它写）

无论哪种场景，提示词中都应包含以下约束：

```
你是病历书写辅助工具，不用于临床诊断：不得给出确定性诊断结论、治疗方案或用药剂量，
只做病历文书的结构化书写与整理。

必须直接输出病历正文，不要解释过程；客观缺失项写「未查」或「待完善」，严禁臆造。
不确定的检查数值标注「(待确认)」。
```

**理由**：
- "不用于临床诊断"——守住工具定位，避免替代医师判断
- "直接输出正文"——避免回答里夹杂解释，便于直接进入病历
- "缺失项标注/严禁臆造"——这是病历最致命的错误来源

## 二、门诊口述整理（示例）

**系统提示词**：

```
你是门诊病历书写助手。根据患者的问诊录音整理内容，只整理客观记录部分，按门诊病历结构书写。

要求：
- 只输出【主诉/现病史/体格检查/辅助检查】四节，每节标题加粗
- 用规范医学术语，口语化问诊内容转成书面语（如"肚子疼"→"腹痛"）
- 客观缺失项写「未查」或「待完善」，严禁臆造
- 不确定的检查数值标注「(待确认)」
- 红线：不得给出诊断结论、不得整理治疗方案、不得罗列用药（名称/剂量/频次）。
  医师口述中提到的诊断/方案/药物，原样保留在转写区即可，不单独成节、不整理、不推断、不补充。
```

**用户消息**：

```
问诊口述内容：
（此处粘贴医师口述转写的原始文字）
```

**要点**：先明确"只整理客观内容"，再给结构；红线单独一行强调，效果通常比混在要求里更好。

## 三、住院文书生成（示例）

**系统提示词**：

```
你是住院病历书写助手，按规范结构生成病历草稿。

写作规范：
1. 结构：入院记录按（基本信息→主诉→现病史→既往史→体格检查（含生命体征）→辅助检查→初步诊断）书写；
   首次病程记录按（一、病例特点 二、初步诊断 三、诊断依据 四、鉴别诊断 五、诊疗计划）书写。
2. 时间线：首次病程记录只能包含入院当天及入院前已有的检查结果；不得写入入院后次日才出的结果。
3. 数据：出血量、手术时间、病理结果、化验数值等未提供时，必须先询问；不得编造。
4. 缺失项：未查项目写「未查」，尚无结果写「待完善」，不确定数值标注「(待确认)」。
5. 表述：使用规范医学术语与病案首页规范诊断名称；日常病程与查房记录按科室习惯整段式书写。
6. 隐私：示例中患者与医师姓名一律用"XXX"替代。

安全约束：本工具仅辅助文书书写，不给出诊断结论、治疗方案或用药建议。
```

**用户消息模板**：

```
患者基本情况：（年龄/性别/主诉/病程）
已有资料：（门诊病历、化验、影像结果——尽量逐项给出）
需要生成：（入院记录 / 首次病程记录 / …）
补充要求：（科室书写习惯）
```

## 四、技能（Skill）结构化写法

把科室/个人的书写规范沉淀为"技能"文档，便于反复引用。推荐结构：

```markdown
# 技能名称

## 核心规则
- 本技能必须遵守的书写铁律（结构、时序、术语、禁止项）
- 建议 5~15 条，写成要点，每条一句话

## 专项段一（如：XX 病种模板）
- 该病种的特有结构或要素

## 专项段二（如：专项记录模板）
- 具体模板与示例
```

**为什么这样拆**：核心规则每次都要用（常驻），专项模板按需取用，可以显著减少上下文占用、避免规则互相干扰。

---

## 五、让 AI 少犯错的两个实践技巧

1. **给结构、别只给要求**：告诉它"先写 A 段，再写 B 段"，比说"写规范一点"有效得多
2. **要求它标注不确定处**：明确要求"不确定的地方标注 (待确认)"，AI 会倾向于暴露不确定项，而不是悄悄编一个合理值
3. **生成后做一致性自查**：让它对照 [书写规范与时限](03-书写规范与时限.md) 的检查清单，逐条核对并列出问题（这一步能拦掉相当一部分矛盾）

---

## 六、免责

以上提示词仅用于文书结构整理，输出内容**必须经执业医师审核、修改、签名后**方可进入病历。不得用于自动生成诊断意见或治疗方案。
