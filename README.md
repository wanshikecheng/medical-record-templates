# 万事柯成 · 病历书写规范库

面向临床医生的 **住院/门诊病历书写规范与结构模板**开源资料库，由「万事柯成病历书写助手」团队整理并持续维护。

本仓库提供的是**文书结构、模块定义与书写规范**，可直接用于：

- 手工书写病历时查阅结构要点
- 医学生/规培医生学习病历书写规范
- 作为 AI 辅助书写的提示词素材（欢迎直接取用）

> 配套 App：万事柯成病历书写助手（Android）—— [下载最新版本](../../../caseagent-releases/releases)
> App 内已将本规范内置为「技能」，可一键套用生成文书草稿。

## 使用方式

1. **查阅**：按文书类型找对应结构，对照书写
2. **套用**：把结构说明作为草稿框架，逐项填写
3. **AI 辅助**：把 `docs/04` 的提示词与 `docs/03` 的规范一并交给 AI，约束其输出规范

- 各医疗机构/科室可能有自己的书写习惯与要求，请以本地规范优先
